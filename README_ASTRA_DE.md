# Astra ByeDPI – russisch lokalisiertes Quellcode-Projekt

Basiert auf ByeDPI Android 1.2.0 (GPL-3.0). Enthält russische Übersetzungen, neuen App-Namen und separate Application-ID. Es ist **keine fertige APK**. Die ursprüngliche ByeDPI-DPI-Engine bleibt vorgesehen, aber die GitHub-Source-ZIP enthält die nötigen Git-Submodule `byedpi` und `hev-socks5-tunnel` nicht. Vor dem Build müssen diese passend nachgeladen werden.

Die Verbindung in Russland kann hier nicht getestet werden; Discord-Sprachanrufe und YouTube sind nicht garantiert. Ein automatischer Strategietester ist noch nicht implementiert. Details in README_ASTRA_RU.md.
