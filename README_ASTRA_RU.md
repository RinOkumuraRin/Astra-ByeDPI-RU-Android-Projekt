# Астра ByeDPI — русская локализация (исходный код)

Это экспериментальная русифицированная сборка **ByeDPI Android 1.2.0**, а не готовый APK. Основана на проекте dovecoteescapee/ByeDPIAndroid, лицензия GPL-3.0 (см. LICENSE). Название приложения и переводы изменены, механика DPI остаётся исходной. Не обещается доступность Discord и YouTube в каждой сети.

## Сборка
1. Установите Android Studio, Android SDK и NDK/CMake по запросу Gradle.
2. ZIP GitHub Source code **не содержит содержимое git submodules** `byedpi` и `hev-socks5-tunnel`. Для сборки нужно получить их из репозитория оригинала с `git clone --recursive https://github.com/dovecoteescapee/ByeDPIAndroid.git` и переключить проект на тег v1.2.0 (если доступен), затем применить файлы локализации и изменение applicationId из этой папки. Или инициализировать подмодули из `.gitmodules` в этом дереве.
3. Откройте проект в Android Studio и соберите Debug APK.
4. При первом запуске Android запросит разрешение VPN. Root не требуется.

## Ограничения
- Реальные голосовые звонки Discord и YouTube необходимо проверять на устройстве в сети РФ.
- Не содержит автоматического теста качества UDP-звонка или автоподбора стратегий.
- Локальный VPN не заменяет шифрованный удалённый VPN для приватности.
- Проверяйте код и подпись перед установкой APK из сторонних источников.
