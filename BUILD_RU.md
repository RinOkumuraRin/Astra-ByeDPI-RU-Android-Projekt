# Астра ByeDPI — сборка APK

Это исходный код, **не готовый APK**. Для сборки нужны интернет, Android SDK/NDK и два открытых нативных компонента.

## Через GitHub Actions
1. Создайте репозиторий на GitHub и загрузите туда содержимое ZIP, включая `.github/workflows/build-apk.yml`.
2. Откройте **Actions** → **Build Astra ByeDPI Android APK** → **Run workflow**.
3. После успешной сборки скачайте артефакт `Astra-ByeDPI-RU-debug-apk` и установите APK на телефон.

**Внимание:** сборка не проверена, поскольку здесь нет Android SDK и доступа к GitHub. Текущие версии нативных компонентов могут быть несовместимы с ByeDPI Android 1.2.0. Приложение не гарантирует работу голосового Discord и YouTube в России. Для проверки качества звонков нужны реальные тесты. Это локальный VPN-интерфейс, а не удалённый зашифрованный VPN.
